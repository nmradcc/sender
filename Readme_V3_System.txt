This directory contains information on the Sender V3 System
This is a self-contained NMRA Baseline Test System

The items in this directory are listed below:

Quickstart Guide to the Decoder Test Board.pdf
	Introductory information on the Sender V3 System.

TS-5300 Configuration Files
	Configuration files for the TS-5300 embedded computer.
	The TS-5300 comes pre-configured with these files.

Sender V3 Enclosure
	Information on the Sender V3 Production Enclosure.
