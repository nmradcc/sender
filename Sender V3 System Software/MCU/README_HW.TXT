DCC sender 2 board.  This directory contains the following
subdirectories:

ORCADWIN\                  Orcad files for Sender Board 2 schematic, layout, and parts
BOOSTER\Noise_injecting    Noise injecting booster schematics
BOOSTER\Glitch_injecting   Glitch injecting booster schematics
PAL\                       PAL source files
